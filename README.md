# bitcoin_chart_project

Django-приложение: графики криптовалют, настройка EMA, проверка стратегии на истории и сравнение с удержанием монеты.

**Python-портфолио Евгения Толмачева** · Начало: 2023 · Python · Django · Django REST Framework · JavaScript · pandas

![Интерфейс bitcoin_chart_project](docs/preview.webp)

## Возможности

- Интерактивный график с настройками стратегии.
- Расчёт сделок на исторических свечах.
- Сравнение результатов стратегии с удержанием актива.

## Что смотреть в коде

Django-модели и представления, REST API, расчёт EMA и взаимодействие Python с графиком в браузере.

Начните с `manage.py`. Названия авторских файлов и их расположение сохранены.

## Подготовка и запуск

Это сохранённая версия пет-проекта, показывающая этап развития навыков. Для воспроизведения создайте отдельное окружение Python, совместимое с зафиксированными зависимостями:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Задайте DJANGO_SECRET_KEY, а для загрузчиков - настройки Binance. Выполните python manage.py migrate. Исторические свечи и рабочая база исключены; загрузчики get_data_*.py показывают подготовку данных. Настройки Django требуют отдельной подготовки для публичного сервера.

Переменные окружения: `BINANCE_API_KEY`, `BINANCE_API_SECRET`, `DJANGO_SECRET_KEY`. Образец находится в [.env.example](.env.example). Сам файл .env автоматически не загружается: исходники читают окружение процесса. Значения нужно передать перед запуском, например в PowerShell:

```powershell
$env:BINANCE_API_KEY = "YOUR_VALUE"
```

После подготовки настроек и необходимых данных основная точка входа:

```powershell
python manage.py runserver
```

`requirements.txt` сохранён из проекта. Это снимок окружения, а не гарантия совместимости с новейшей версией Python. Для старых проектов могут потребоваться соответствующая версия Python и настройка системных компонентов.
